# 🔐 Password Strength Checker

A simple Python-based **Password Strength Checker** that evaluates the strength of a password based on common security requirements.

This project was developed as part of my **Cybersecurity Internship at Prodigy InfoTech**.

---

## 📌 Project Overview

Weak passwords are one of the common causes of account compromise.

This project checks whether a password follows basic security practices such as:

- Minimum password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

Based on these conditions, the program determines the overall strength of the password.
